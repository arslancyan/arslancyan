# ARSLANCYAN Portfolio — GitHub Pages

## Structure
- `index.html` — complete website
- `images/` — artwork, hero image, GIFs and video posters
- `videos/` — 3 timelapse MP4 files

## Publish
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload everything in this folder.
3. GitHub → repository → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`, Save.
6. Open `https://YOURUSERNAME.github.io`.

## Important replacements
- Replace `YOUR_TELEGRAM_USERNAME` in `index.html`.
- Replace `your@email.com`.
- Put your artwork into `images/`.
- Put your 3 timelapses into `videos/`.
- Use `hero.jpg` for the large hero artwork.
- To make the whole site visibly use one of your artworks as a background, name that image `site-background.jpg`.
